# Prompt Shelf for SillyTavern

SillyTavern의 Chat Completion 프리셋을 이름과 버전별로 정리하고 빠르게 전환하는 UI 확장입니다. 기존 프리셋 데이터는 건드리지 않고, 기본 프리셋 선택기 위에 별도의 선반을 추가합니다.

## 주요 기능

- `감성 프롬프트 13.2`, `감성 프롬프트 v14`, `감성 프롬프트 (rev 15)`처럼 끝에 붙은 버전을 자동 인식
- 버전을 제거한 이름의 유사도를 계산해 같은 계열을 자동 그룹화
- 사용자가 직접 그룹을 만들고 자동 분류 결과를 덮어쓰기
- 최신 버전부터 정렬하고 현재 사용 중인 프리셋을 강조
- 기본 퀵 슬롯 1개와 하단 `＋` 버튼으로 필요한 만큼 확장하는 원터치 전환
- 각 그룹 서랍 및 전체 접기/펼치기, 검색, 그룹 필터, 모바일 반응형 UI
- `＋`, `✎`, `×`, `▾`, `📌`, `☷` 중심의 직관적인 관리 버튼
- 그룹 이름과 SillyTavern 원본 프리셋 이름을 선반에서 바로 변경
- 현재 SillyTavern 테마의 본문·강조·배경·테두리 색상을 자동 반영
- 기본적으로 접힌 버전 서랍과 항상 표시되는 전체 프리셋 이름
- 사용자 그룹(`◆`)과 자동 버전 그룹(`✦`)을 분리해서 조회
- 데스크톱 드래그 앤 드롭 및 모바일 `＋/−` 방식으로 그룹 구성
- 원본은 유지하는 그룹 제외와 확인 토스트를 거치는 별도 원본 삭제
- 체크박스로 여러 프리셋을 선택해 한 번에 그룹에 추가
- 버전 최신/오래된순 및 이름 오름/내림차순 정렬
- 상단 장식 그라데이션 없이 SillyTavern 테마 배경색만 사용
- 기존 프롬프트 서랍을 다른 서랍 아래에 넣어 만드는 계층 구조
- `⇥ 이동`과 `⧉ 복제`를 통한 단일·다중 서랍 배치
- 설정과 사용자 그룹은 SillyTavern 확장 설정에 저장

## 설치

SillyTavern에서 **Extensions → Install Extension**을 열고 아래 주소를 붙여 넣습니다.

```text
https://github.com/gakumasu1717-cloud/prpt.git
```

설치 후 **AI Response Configuration → Chat Completion Presets** 위에 Prompt Shelf가 나타납니다. 보이지 않으면 페이지를 한 번 새로고침하세요.

소개 페이지용 HTML은 [소개글.html](/D:/Silly/s/소개글.html)에 있습니다. 게시판 본문에 그대로 붙여 넣거나 필요한 부분만 사용하면 됩니다.

## 사용법

1. 기본 퀵 슬롯은 1개입니다. 빈 슬롯의 `＋`를 누르면 현재 프리셋이 등록되고, 슬롯 목록 아래 별도 `＋`로 슬롯을 늘립니다. 등록된 슬롯의 `↻`은 교체, `×`는 해제입니다.
2. 저장된 슬롯의 이름 영역을 누르면 해당 프리셋으로 즉시 전환됩니다.
3. 상단 `＋`는 그룹 생성, `⇅`는 전체 접기/펼치기, `☷`는 그룹 관리 모드입니다.
4. **프롬프트 선반** 제목을 누르면 선반 전체가 접힙니다. 각 서랍은 큰 `▾` 또는 그룹 이름을 눌러 접습니다.
5. `◆`는 사용자 그룹만, `✦`는 자동 버전 그룹만 보여줍니다.
6. 데스크톱에서는 프리셋을 다른 서랍에 드롭합니다. 서랍 아래 `＋`에서는 여러 프리셋을 체크한 뒤 `✓` 한 번으로 추가하고, `−`는 그룹에서만 제외합니다.
7. `✎`로 그룹명 또는 실제 프리셋명을 변경합니다. 관리 모드의 `🗑`는 확인 토스트 후 원본 프리셋을 삭제합니다.
8. 검색창 아래 정렬 메뉴에서 버전 또는 이름 기준 정렬을 선택합니다. Extensions 패널에서는 자동 그룹화와 유사도를 조절할 수 있습니다.
9. 기존 프롬프트 서랍 아래 `▣⇣`를 누르면, 현재 서랍 아래에 넣을 **기존 서랍**을 선택할 수 있습니다. 새 빈 서랍을 만들지 않으며, 선택한 서랍의 프롬프트는 그대로 유지됩니다.
10. `⇥ 이동`은 프리셋을 대상 서랍 한 곳에만 배치합니다. `⧉ 복제`는 원래 위치를 유지하면서 여러 서랍에 함께 표시합니다.
11. 데스크톱에서는 하위 서랍 제목을 다른 상위 서랍으로 드래그하고, 모바일에서는 관리 모드의 선택 상자로 배정할 수도 있습니다.

상위 서랍과 복제 배치는 프리셋을 정리하는 메타데이터일 뿐입니다. 상위 서랍의 `×`를 눌러 해제하거나 복제 위치에서 `−`를 눌러도 원본 프리셋은 삭제되지 않습니다. 하위 서랍을 다른 하위 서랍 위로 드롭하면 현재 이동·복제 모드에 따라 프리셋이 이동되거나 함께 표시됩니다.

그룹 유사도를 높이면 이름이 거의 같은 프리셋만 묶이고, 낮추면 표기가 조금 다른 이름도 같은 계열로 묶입니다.

## 호환성과 데이터

- 최신 SillyTavern의 `SillyTavern.getContext()`와 `data-preset-manager-for="openai"` 프리셋 선택기를 사용합니다.
- 프리셋 JSON을 복사하거나 변경하지 않습니다. 이 확장을 제거해도 원본 프리셋은 그대로 남습니다.
- Prompt Shelf의 `✎` 버튼으로 이름을 바꾸면 사용자 그룹·퀵 슬롯·복제 배치도 함께 새 이름으로 이전됩니다. SillyTavern 기본 UI 등 확장 밖에서 이름을 바꾸면 연결을 다시 지정해야 할 수 있습니다.
