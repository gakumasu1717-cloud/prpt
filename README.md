# Prompt Shelf for SillyTavern

SillyTavern의 Chat Completion 프리셋을 이름과 버전별로 정리하고 빠르게 전환하는 UI 확장입니다. 기존 프리셋 데이터는 건드리지 않고, 기본 프리셋 선택기 위에 별도의 선반을 추가합니다.

## 2.0에서 달라진 점

- **기호 버튼 제거** — `▣⇣`, `⇥`, `⧉`, `◈/◆/✦` 같은 기호를 없애고, 모든 동작을 글자로 적힌 `⋯` 메뉴로 옮겼습니다.
- **관리 모드 삭제** — 모드를 켜야만 보이던 그룹 편집·프리셋 삭제·그룹 지정이 이제 항상 접근 가능합니다.
- **전역 이동/복제 모드 삭제** — 배치 방식은 보낼 서랍을 고르는 순간에 선택합니다. 드래그는 기본 이동, `Ctrl`(맥은 `⌥`)을 누른 채 놓으면 복제입니다.
- **Claude 스타일 디자인** — 크림/코랄 팔레트, 1px 테두리, 넉넉한 여백으로 다시 그렸습니다.
- **외관 전환 버튼** — 헤더의 아이콘을 누를 때마다 `테마 따라가기 → 라이트 → 다크` 순으로 바뀝니다.
- **검색 성능 개선** — 검색어를 입력해도 선반을 다시 그리지 않아 입력 포커스가 끊기지 않습니다.

## 주요 기능

- `감성 프롬프트 13.2`, `감성 프롬프트 v14`, `감성 프롬프트 (rev 15)`처럼 끝에 붙은 버전을 자동 인식
- 버전을 제거한 이름의 유사도를 계산해 같은 계열을 자동 그룹화
- 사용자가 직접 그룹을 만들고 자동 분류 결과를 덮어쓰기
- 최신 버전부터 정렬하고 현재 사용 중인 프리셋을 강조
- 기본 퀵 슬롯 1개와 `+ 슬롯 추가`로 필요한 만큼 늘리는 원터치 전환
- 서랍별·전체 접기/펼치기, 검색, 그룹 필터, 모바일 반응형 UI
- 그룹 이름과 SillyTavern 원본 프리셋 이름을 선반에서 바로 변경
- 사용자 그룹과 자동 버전 그룹을 `전체 / 내 그룹 / 자동` 탭으로 분리 조회
- 데스크톱 드래그 앤 드롭 및 `⋯ → 서랍으로 보내기`로 그룹 구성
- 원본은 유지하는 서랍 제외와, 확인 토스트를 거치는 원본 삭제
- 체크박스로 여러 프리셋을 선택해 한 번에 서랍에 추가
- 버전 최신/오래된순 및 이름 오름/내림차순 정렬
- 기존 서랍을 다른 서랍 아래에 넣어 만드는 계층 구조
- 설정과 사용자 그룹은 SillyTavern 확장 설정에 저장

## 설치

SillyTavern에서 **Extensions → Install Extension**을 열고 아래 주소를 붙여 넣습니다.

```text
https://github.com/gakumasu1717-cloud/prpt.git
```

설치 후 **AI Response Configuration → Chat Completion Presets** 위에 Prompt Shelf가 나타납니다. 보이지 않으면 페이지를 한 번 새로고침하세요.

소개 페이지용 HTML은 [소개글.html](소개글.html)에 있습니다. 게시판 본문에 그대로 붙여 넣거나 필요한 부분만 사용하면 됩니다.

## 사용법

### 빠른 전환

1. 기본 퀵 슬롯은 1개입니다. 빈 슬롯을 누르면 현재 프롬프트가 등록되고, 아래 `+ 슬롯 추가`로 슬롯을 늘립니다.
2. 저장된 슬롯의 이름 영역을 누르면 해당 프리셋으로 즉시 전환됩니다. 오른쪽 아이콘은 각각 교체와 비우기입니다.

### 찾기

3. 검색창에 이름 일부를 입력하면 일치하는 프롬프트만 남고 서랍이 자동으로 펼쳐집니다.
4. `전체 / 내 그룹 / 자동` 탭으로 그룹 종류를 나눠 보고, 그 아래 칩으로 특정 서랍만 볼 수 있습니다.
5. 선반 제목을 누르면 선반 전체가, 서랍 이름을 누르면 해당 서랍이 접힙니다. 헤더의 목록 아이콘은 모든 서랍을 한 번에 접고 폅니다.

### 정리

6. **프롬프트의 `⋯`** — 이름 변경 / 서랍으로 보내기(이동·복제 선택) / 새 서랍 만들어 넣기 / 이 서랍에서 빼기 / 프롬프트 삭제
7. **서랍의 `⋯`** — 서랍 이름 변경 / 프롬프트 추가 / 기존 서랍 넣기 / 상위 서랍 지정 / 서랍 삭제
8. **상위 서랍의 `⋯`** — 이름 변경 / 상위 서랍 해제
9. 데스크톱에서는 프롬프트나 서랍 제목을 다른 서랍 위로 끌어다 놓습니다. 그냥 놓으면 **이동**, `Ctrl`·`⌥`·`Meta`를 누른 채 놓으면 **복제**입니다.
10. 서랍 안 `+ 프롬프트 추가`에서 체크박스로 여러 개를 고른 뒤 한 번에 넣습니다.

### 설정

11. 헤더 왼쪽 아이콘(◑ / ☀ / ☾)을 누르면 **테마 따라가기 → 라이트 → 다크** 순으로 화면 색이 바뀝니다.
12. Extensions 패널의 Prompt Shelf 항목에서 선반 표시, 자동 그룹화, 그룹 유사도를 조절합니다.

상위 서랍과 복제 배치는 프리셋을 정리하는 메타데이터일 뿐입니다. 상위 서랍을 해제하거나 서랍에서 빼도 원본 프리셋은 삭제되지 않습니다.

그룹 유사도를 높이면 이름이 거의 같은 프리셋만 묶이고, 낮추면 표기가 조금 다른 이름도 같은 계열로 묶입니다.

## 색상

선반 헤더의 아이콘을 누르면 세 가지 외관을 순환합니다.

| 아이콘 | 모드 | 동작 |
| --- | --- | --- |
| ◑ `circle-half-stroke` | **테마 따라가기** (기본값) | SillyTavern의 `--SmartTheme*` 색을 그대로 사용합니다. 주변 UI와 이질감이 없습니다. |
| ☀ `sun` | 라이트 | Claude 라이트 팔레트 (`#FAF9F5` 배경 / `#C96442` 코랄) |
| ☾ `moon` | 다크 | Claude 다크 팔레트 (`#262624` 배경 / `#D97757` 코랄) |

테마 따라가기 모드에서는 SillyTavern 배경색의 상대 휘도를 읽어 그림자 농도를 라이트·다크에 맞춰 조정합니다. 선택한 모드는 확장 설정에 저장됩니다.

## 호환성과 데이터

- 최신 SillyTavern의 `SillyTavern.getContext()`와 `data-preset-manager-for="openai"` 프리셋 선택기를 사용합니다.
- 프리셋 JSON을 복사하거나 변경하지 않습니다. 이 확장을 제거해도 원본 프리셋은 그대로 남습니다.
- Prompt Shelf에서 이름을 바꾸면 사용자 그룹·퀵 슬롯·복제 배치도 함께 새 이름으로 이전됩니다. SillyTavern 기본 UI 등 확장 밖에서 이름을 바꾸면 연결을 다시 지정해야 할 수 있습니다.
- 1.x에서 저장한 설정은 그대로 읽힙니다. 더 이상 쓰이지 않는 `transferMode` 값은 무시됩니다.
